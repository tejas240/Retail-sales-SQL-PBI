# Retail-sales-SQL-PBI
📊 Retail Sales Analysis with SQL + Power BI
I recently completed a project analyzing retail sales data to uncover key business insights.
🔍 Using SQL, I created and queried the database to identify:
1. Top 5 customers by total spending
2. Monthly revenue trends
3. Category‑wise contribution to overall sales
📈 With Power BI, I built an interactive dashboard that highlights:
KPIs (Total Revenue, Total units sold)
1. Sales trends over time
2. Category performance breakdown
💡 Key insight: Electronics contributed nearly 89% of total revenue, with March showing peak sales.
This project helped me strengthen my skills in database querying, data visualization, and storytelling — turning raw data into actionable business insights.
